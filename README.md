# ニッポン地理テスト

旅行や日常会話で役立つ日本地理を、全20問で楽しく学べるクイズサイトです。

## 主な機能

- 標準問題10問＋高難度問題10問
- 1問ずつ回答するクイズUI
- 結果のスコア表示
- LINE共有、Discord用の結果コピー、リンクコピー
- 過去5回分のスコアをブラウザ内に保存
- スマートフォン対応

## GitHub Pagesで公開する

このプロジェクトは静的サイトとして公開できます。GitHub Actionsで `npm run build` を実行し、生成された `dist` をPagesにデプロイしてください。

```bash
npm install
npm run build
```

GitHubリポジトリの Settings > Pages で、Actionsを公開元に選択します。公開先がサブパスになる場合は、リポジトリ名に合わせてアセットのベースパスを設定してください。

## ローカルで確認する

```bash
npm run dev
```
